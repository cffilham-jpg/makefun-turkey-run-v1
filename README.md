Thanksgiving dinner has other plans. So do you.

An original side-scrolling turkey escape game: flutter over glowing ovens, duck giant carving knives, hop fences and hay, and follow the corn to the Freedom Gate at 1,500 metres. A farmer with a net is always on your tail. Three feathers, one sunset, no second helping.

## Play locally

Run `node serve.ts` with Node 22.18+ and open `http://127.0.0.1:8080`. No install, build, external assets, or internet connection is needed. Canvas artwork and WebAudio music/effects are generated by the game.

| Action | Controls |
| --- | --- |
| Start | Enter / click Start |
| Jump / flutter higher | Hold Space / Up / W / canvas click / Jump button |
| Duck | Hold Down / S / Duck button |
| Sprint | Hold Right / D / Sprint button |
| Pause / resume | P / Pause / resume button |
| Restart | R / end-screen button |
| Sound | Sound button |

Corn refills sprint stamina and adds 75 points. Clean dodges grow your lead; hits lose a feather and let the farmer gain ground. Score is metres + corn × 75 + 2,500 for escaping. The route becomes faster and denser through the farmyard, cookhouse and last fence. Best distance saves locally when storage is available.

## Package and screenshots

`node main.ts` writes `out/` locally. `MAKEFUN_OUTPUT_DIR=/path node main.ts` selects another destination; the grading sandbox's `/output` is used when present. The entry uses the unmodified kit dossier library and its exact gate caps.

`shots.json` lists deterministic browser states. `?shot=play` freezes the 640 m oven jump with two feathers and the farmer 1.5 m behind; `?shot=start` shows the menu and `?shot=end` the escape celebration. Add `?seed=7` for a repeatable run. Screenshots are actual 1280×720 browser renders.

Source jobs: `config.js` tuning/scoring; `audio.js` synthesized sound; `input.js` keyboard/pointer controls; `world.js` physics, chase, hazards and pickups; `render.js` procedural art and UI; `main.js` loop and screens. `serve.ts` is a local static server. This repository is built and verified only; submission is handled separately.
